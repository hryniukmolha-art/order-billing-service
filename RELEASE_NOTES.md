# Release Notes — v1.1.0 (vs v1.0.0)

## Added
- Спеціальний базовий тариф доставки **80.0** для міста `"Kyiv"` (збережено **50.0** для `"Ivano-Frankivsk"` та **110.0** для інших міст).
- Явний параметр ставки податку `tax_rate` (зі значенням за замовчуванням `0.20`) та окрема функція `process_tax_exempt_invoice(...)`.

## Changed
- Коефіцієнт вартості доставки за вагу збільшено з `12.0` до `15.0` за кілограм.
- Виконано рефакторинг модуля білінгу до **Data Coupling**: функції приймають лише необхідні примітивні дані або явні параметри без побічних ефектів.

## Breaking Changes
- Видалено глобальну змінну `GLOBAL_TAX_RATE` (усунуто **Common Coupling**).
- Функція розрахунку доставки більше не приймає об'єкт профілю користувача — замість нього передається рядок `city` (усунуто **Stamp Coupling**).
- Видалено параметр `mode_flag` та функцію `process_invoice(...)` (усунуто **Control Coupling**); замість них використовуються `process_standard_invoice(...)` і `process_tax_exempt_invoice(...)`.
